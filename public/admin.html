Прохождения

Ссылки для получательниц

Для каждой девушки — своя ссылка с её именем. В записях будет видно, кто по какой ссылке пришёл.

Все надписи

Всё сохраняется автоматически и остаётся после перезапуска. У каждого языка — свой набор надписей.

Подстановки: {name} имя получательницы · {from} твоё имя · {fromDat} кому (Максиму) · {fromIns} с кем (Максимом) · {date} выбранный день · {time} выбранное время

Язык приглашения

Все надписи уже переведены: дни недели, месяцы и формат даты переключаются сами. Выбранный язык будет у основной ссылки и у всех ссылок, где стоит «по умолчанию».

Для отдельной девушки язык можно выбрать во вкладке «Ссылки»: например, основная анкета на русском, а ссылка для Оли — на украинском. Поправить перевод можно во вкладке «Тексты»: переключи там язык сверху.
