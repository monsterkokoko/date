# Свидание ♡

Анкета-приглашение на свидание с котиком, убегающей кнопкой «Нет», выбором дня и времени, анимацией письма и финальным экраном. В админке видно запись каждого прохождения.

## Запуск

- **`start.bat`** — сервер на `http://localhost:3333` и публичная ссылка через Cloudflare Quick Tunnel (появится в консоли и в шапке админки).
- **`start-local.bat`** — только локально, без туннеля.

Нужен Node.js 18+. Для туннеля нужен `cloudflared` (`winget install Cloudflare.cloudflared`).

При первом запуске открой `http://localhost:3333/admin` и придумай пароль. Сделать это можно только с этого компьютера, через туннель нельзя.

## Адреса

| Адрес | Что это |
|---|---|
| `/` | анкета с именем по умолчанию |
| `/p/<ссылка>` | персональная ссылка (создаётся в админке) |
| `/admin` | админка |
| `?preview=1` | посмотреть анкету без записи |

## Данные

Всё хранится в папке `data/`: `config.json` (тексты и настройки), `auth.json` (пароль), `sessions/` (записи), загруженная музыка.
Quick-tunnel ссылка меняется при каждом перезапуске.
